# TokenBar

macOS 메뉴바에서 **Claude Code 토큰 사용량**을 보는 앱입니다.

비용이 아니라 **현재 5시간 윈도우 사용량**을 먼저 보여줍니다.
— 구독자가 실제로 걱정하는 건 요금이 아니라 **한도에 걸리는 순간**이기 때문입니다.

```
메뉴바   →  현재 윈도우 토큰 (또는 추정 비용 / 호출 횟수)
클릭     →  윈도우 · 오늘 · 이번 주 · 모델별 내역
```

---

## 설치

[Releases](https://github.com/leetomo2528/tokenbar/releases)에서 `.zip`을 받아
압축을 풀고 `TokenBar.app`을 **응용 프로그램** 폴더로 옮기세요.

### ⚠️ 처음 열 때 막힙니다

이 앱은 **코드 서명이 안 되어 있습니다.** 애플 개발자 계정(연 $99)이 없어서입니다.
숨기지 않고 적어둡니다 — 처음 실행 시 Gatekeeper가 막습니다.

여는 방법:

1. 응용 프로그램에서 **TokenBar를 우클릭 → 열기**
2. 경고창에서 한 번 더 **열기**

믿기 어려우면 코드를 직접 보고 실행하셔도 됩니다:

```bash
git clone https://github.com/leetomo2528/tokenbar
cd tokenbar
npm install
npm start
```

사이드에 아이콘이 아니라 **숫자가 뜨는 방식**입니다. 숨은 것 같으면
메뉴바 오른쪽을 확인하세요. 우클릭하면 표시 항목을 바꿀 수 있습니다.

## 어떻게 동작하나

Claude Code는 세션을 로컬에 JSONL로 기록합니다.

```
~/.claude/projects/<인코딩된-프로젝트-경로>/<세션ID>.jsonl
```

`type:"assistant"` 라인의 `message.usage`에서 토큰 수를 읽어 집계합니다.

- **네트워크 요청 없음.** 전부 로컬 파일 읽기만 합니다
- **계정 없음.** 로그인할 게 없습니다
- **쓰기 없음.** 로그 파일을 읽기만 하고 건들지 않습니다
- 변경된 파일만 다시 읽습니다 (mtime·size 캐시)

## 알고 써야 하는 것

### 비용은 추정치입니다

`src/pricing.js`의 단가표로 계산합니다. 요금은 수시로 바뀝니다.
**구독(Pro·Max) 사용자라면 실제 결제액과 무관합니다.** "이 정도 썼다"를 가늘하는 숫자로만 보세요.

### 윈도우는 단순 롤링 윈도우입니다

"최근 5시간"을 계산할 뿐, Anthropic이 실제로 어떻게 한도를 잰는지는
공개된 정보가 없습니다. **한도 예측이 아니라 추세 파악용**입니다.
정확한 잔여량은 Claude Code에서 `/usage`를 쓰세요.

### 지금은 Claude Code만 됩니다

Codex·Cursor는 로그 형식을 확인한 뒤에 붙일 예정입니다.
확인 안 된 걸 된다고 적지 않겠습니다.
